## Project Description
This project implements a Tier-3 Multi-Domain Intelligence Platform developed as part of CST1510 Coursework 2.
The system integrates three operational domains:
IT Operations
Cybersecurity
Data Science
The platform is built using Python, Streamlit, and SQLite, and provides:
Secure authentication
Role-aware session handling
Interactive dashboards with filters and charts
Full CRUD functionality
Domain-specific AI assistants for decision support
Although all three domains are implemented, the coursework report primarily focuses on the IT Operations domain, as required by the assessment brief.
## How to run
download the folder then change directory to the folder then type streamlit run Home.py
if that does not work try python -m streamlit run Home.py
put your API key in the .env file
